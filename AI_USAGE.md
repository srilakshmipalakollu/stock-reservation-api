# AI Usage Report

## 1. AI Tools Used
ChatGPT: Used as a learning and development assistant during the implementation of the Stock Reservation API.

## 2. How AI Was Used
AI assistance was used for the following activities:

- Concept clarification: Understanding Spring Boot, REST APIs, JPA/Hibernate, database transactions, and repository responsibilities.
- Implementation guidance: Understanding how to structure controllers, services, repositories, entities, DTOs, and exception handling.
- Validation and business logic: Reviewing approaches for request validation, reservation lifecycle transitions, stock availability checks, and idempotent confirmation and cancellation.
- Testing: Understanding unit tests, database-backed integration tests, transaction rollback, and concurrent reservation scenarios.
- Debugging: Investigating application configuration, database connection issues, test failures, and Git workflow errors.
- Documentation: Preparing and reviewing project setup instructions, API usage, testing instructions, and project documentation.

## 3. Human Review and Verification
AI suggestions were reviewed and adapted during implementation. The application was run locally, API endpoints were exercised, and automated tests were executed to verify the implemented behavior.

The test suite completed successfully with 15 tests and no failures or errors at the time of verification.

## 4. Limitations and Responsibility
AI-generated suggestions may contain mistakes, inaccuracies, or incorrect assumptions. I critically reviewed the generated suggestions, identified and corrected errors, refined the implementation, and verified the important functionality through code review and testing.

I am responsible for understanding the submitted implementation, explaining the design decisions, and making any necessary corrections.

## 5. Reflection
AI assistance helped me understand unfamiliar concepts, troubleshoot development issues, and improve the testing and documentation process. Reviewing and testing the resulting code was an important part of completing the project.
